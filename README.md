# NeoFluxer

![Preview](/Assets/Main%20Chat%20View.png)

NeoFluxer is a Major Overhaul of the Fluxer UI.</br>
It aims to give the fluxer app a more Cyber-Aestetic, while maintaining good coverage of what matters.</br>

NeoFluxer has several Configurable settings you can toggle. Edit the theme file to adjust these.
